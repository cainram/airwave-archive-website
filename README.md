# Airwave Archive: the website

The website for [Airwave Archive](https://github.com/cainram/airwave-archive),
a calm, self-hosted home for your radio recordings.

Plain HTML and CSS: no scripts, no build step, no tracking. Light and dark
follow the visitor's own setting. Served as static files by
[Caddy](https://caddyserver.com/).

The screenshots come from a demo library of invented series with generated
artwork; no real recordings or cover art appear on the site.
